# Catalog Usage

Use the catalog in three passes:

1. Classification
   Map the user's request onto the nearest safe category and skill family.
2. Phasing
   Decide whether the skill belongs in `now`, `next`, `after-task-lifecycle`, or `frontier`.
3. Realization
   Build only the top-priority skill folders for the current BotBoy maturity level.

Use safe substitutions for risky asks:

- "attack coding" -> defensive adversarial testing and hardening
- "military" -> resilience, logistics, crisis simulation, and decision-support only
- real intrusion or weaponization -> do not build
- harmful wet-lab or operational bio work -> do not build

Use the JSON catalog for filtering and automation.
Use the Markdown catalog for strategy and human review.
