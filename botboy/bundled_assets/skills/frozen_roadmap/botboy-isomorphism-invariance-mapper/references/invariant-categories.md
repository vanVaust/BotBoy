# Invariant Categories

Use these invariant classes:

1. interface invariants
   fields, status meanings, or route semantics that must stay stable
2. control-flow invariants
   decision boundaries, approval paths, or execution phases that must preserve meaning
3. data-shape invariants
   record relationships, identifiers, or payload roles that must survive transformation
4. observability invariants
   traceability, audit hooks, or metrics continuity that must remain intact

State the invariant before comparing the structures.
