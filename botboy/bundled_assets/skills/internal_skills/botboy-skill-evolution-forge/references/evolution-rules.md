# Evolution Rules

Use these heuristics:

1. Split a skill when it has more than one stable trigger family.
2. Split a skill when its references or scripts serve different jobs.
3. Merge skills when users would naturally ask for them with the same language.
4. Rename a skill when the current name hides the actual action.
5. Retire a skill when another one fully subsumes it and the trigger ambiguity is gone.

Apply the change in this order:

1. catalog
2. SKILL metadata
3. references
4. scripts
5. migration note if needed
