# Reflection Loop Patterns

Use these reflection patterns:

1. pre-execution critique
   catch risky or weak plans before action
2. post-execution review
   extract lessons from an observed run
3. branch comparison
   compare two candidate actions before choosing
4. eval-informed reflection
   turn recurring failures into durable guidance

Good reflection loops:

- name their trigger condition
- produce structured output
- change an operational decision
- leave evidence in traces, history, or eval artifacts
